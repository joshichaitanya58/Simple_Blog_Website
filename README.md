# Simple Blog Website

## Overview
A basic blog website where users can view, add, edit, and delete blog posts using HTML, CSS, and JavaScript (localStorage).

## Features
- View blog posts
- Add new post via form
- Edit existing posts
- Delete posts
- Responsive, clean design

## How to Use
1. Open `index.html` in your browser.
2. Use the "New Post" button to create a new blog post.
3. Posts are saved in your browser's localStorage.

## Folder Structure
- `css/` - Stylesheet
- `js/` - JavaScript logic
- `index.html` - Homepage
- `new_post.html` - New post form
